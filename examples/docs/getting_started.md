# Getting Started Guide

This guide walks you through the initial setup and basic configuration.

## Prerequisites

Ensure you have a terminal emulator capable of UTF-8 and 24-bit truecolor.
Once your environment is verified, proceed to the installation steps.

## Installation

```bash
pip install -e .
```

After installation, verify the CLI:

```bash
mdok --help
```
