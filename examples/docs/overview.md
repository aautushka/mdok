## Key Concepts

Here is an overview of how components connect:

* **CLI Runner**: Parsed arguments and config files.
* **Rendering Pipeline**: Evaluates styles, badges, and layout tables.
* **Pager & Editor**: Seamless handover to terminal viewers.
